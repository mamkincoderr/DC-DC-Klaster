# Модели DC-DC 2 кВт для QSpice — DAB и CLLLC

Двунаправленный изолированный преобразователь 360…430 В ↔ 46…57 В (LiFePO4 16S),
номинал 2 кВт. Файлы этой папки — актуальные модели, результаты которых приведены
в [`MyDOC/ЭП_8_Моделирование.md`](../MyDOC/EP_DCDC.md#8-моделирование) (раздел 8
эскизного проекта) и в [`MyDOC/EP_DCDC.md`](../MyDOC/EP_DCDC.md), раздел 7.5.

## Что нужно для запуска

**QSpice** (бесплатная, Qorvo) — больше ничего.

Все файлы должны лежать в одной папке. `psm_4outputs_dab.dll` обязан лежать рядом
с `All_bridge_60kHz_v1.3.0.qsch` — иначе DAB не запустится (ошибка на блоке X1).
CLLLC (`CLLC_v1.3.1.qsch`) DLL не требует — модулятор реализован без него ради
скорости счёта (см. `CLLC_СТАТУС.md`).

Запуск: открыть `.qsch`, нажать **F2** (Run).

## Важно про версии

`DAB_СТАТУС.md` фиксирует переход от несимметричной затворной цепи и мёртвого
времени первых версий к финальным **22 Ом/200 нс (ВВ)** и **12 Ом/150 нс (НВ)**,
устранившим сквозной ток через ёмкость Миллера (раздел 8.2.3 отчёта). Раздел 7.5
эскизного проекта («Проверка моделированием», п. 7.5.9) ссылается на более раннюю
`All_bridge_60kHz_v1.2.0.qsch` — этот номер верен только для того текста; численные
результаты раздела 8 получены уже на v1.3.0.

## Что не вошло в репозиторий

Рабочая папка на диске (`DC-DC/QSpice/`) содержит несколько сотен промежуточных
файлов развёрток (`dab_runs/`, `cllc_runs/`, версии `v1.0.0`…`v1.2.1`, `.qraw`,
`.log`) — черновые прогоны при подборе параметров, не результаты. В репозиторий
включены только файлы, на которые прямо ссылается текст эскизного проекта.
