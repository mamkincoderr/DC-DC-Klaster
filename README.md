# DC-DC Кластер

Документация и материалы по разработке двунаправленного изолирующего DC-DC преобразователя (шифр **ДЦ-ДД-001**) — подсистемы накопления энергии кластерного инверторного стабилизатора «КилоГерц».

Топология: Dual Active Bridge (DAB) / Phase-Shifted Full Bridge. ВВ-сторона 360–430 В DC, НВ-сторона 42–58 В (LiFePO4 16S), мощность 1,5–2 кВт.
